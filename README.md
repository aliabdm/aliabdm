## 🚀 Featured Project

### 👻 [Ghost Job Detector](https://github.com/aliabdm/Ghost-Job-Detector) ⭐ NEW

AI-powered web app built with **Gemma 4** that analyzes job descriptions and detects:
- ghost jobs
- scams
- suspicious listings
- misleading HR language

The system translates corporate job descriptions into practical real-world meaning and helps candidates decide whether a role is actually worth applying for.

**🔗 Live Demo:** https://ghost-job-detector-rlcx.vercel.app/

**Tech:** `Next.js` `TypeScript` `OpenRouter` `Gemma 4` `Vercel`

#### Key Features
- 🤖 AI-powered job analysis
- 🚩 Ghost-job & scam detection
- 🧠 HR language translation layer
- 👤 Candidate-fit analysis
- 🔄 Multi-model Gemma fallback system
- 📱 Mobile responsive UI
